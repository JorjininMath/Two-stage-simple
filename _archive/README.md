# Archive

This folder keeps retired experiment entrypoints that are useful for historical
reference but are not part of the current public workflow.

Tracked archive folders should contain source code, configs, and README files
only. Generated outputs, logs, figures, caches, and local data remain ignored.

Current tracked archive entries:

- `exp_wsc_2026/` — historical WSC 2026 table-reproduction runner. The active
  journal-scale CKME-DCP workflow now lives in `exp_adaptive_h/`.
