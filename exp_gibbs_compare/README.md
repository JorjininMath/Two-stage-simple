# Legacy Gibbs-comparison entry point

This directory is compatibility-only. Active code, configuration, and outputs
belong under `experiments/gibbs_compare/`.

Use the canonical command for new work:

```bash
python -m experiments.gibbs_compare.run_gibbs_compare --help
```

The legacy command `python exp_gibbs_compare/run_gibbs_compare.py` remains
available for existing scripts.
